1. Project Goal
===============================================================================

Long-term project goal:
- Predict soil health using measured EC, pH, and water content.
- Use deep learning or other machine-learning methods where appropriate.

Current agreed modeling architecture:

1. Forward model:
   soil-health state variables + soil context variables -> EC

2. Inverse model:
   measured signals + soil context variables -> soil-health state variables

3. Optional scoring layer:
   predicted soil-health state variables -> crop-specific composite health score

Agreed variable grouping:

Soil-health state variables:
- N
- P
- K
- CEC
- OC
- Moisture

Soil context variables:
- Clay
- Silt
- Sand
- Coarse
- pH_CaCl2
- pH_H2O
- CaCO3

Interpretation:
- Clay belongs in the context block because it conditions how state variables
  translate into EC.
- Moisture is an expected state variable and placeholder, even when absent from
  the current datasets.

5. Current Forward Model
===============================================================================

Main scripts:
- matlab\fit_forward_soil_ec_model.m

Outputs:

- outputs\forward_soil_ec\forward_model_predicted_vs_actual.png
- outputs\forward_soil_ec\forward_soil_ec_model.mat

Current forward model mathematical form:

Let:
- y = log10(EC)

Then:
- y_hat = beta0
        + sum_i beta_state_i * g_i(state_i)
        + sum_j beta_context_j * h_j(context_j)
        + sum_(i,j in selected pairs) beta_ij * g_i(state_i) * h_j(context_j)

Prediction:
- EC_hat = 10^(y_hat)

Current state variables:
- N
- P
- K
- CEC
- OC
- Moisture if available

Current context variables:
- Clay
- Silt
- Sand
- Coarse
- pH_CaCl2
- pH_H2O
- CaCO3

Current transforms:
- log1p used for skewed positive variables such as:
  N, P, K, CEC, OC, CaCO3, Coarse, Clay, Moisture
- raw values used for less skewed variables

Current interaction structure:
- each state variable interacts with:
  Clay, Silt, Sand, pH_H2O, pH_CaCl2, CaCO3

Current run on linked stable-point table from data_comp:
- Rows used: 1787
- Physics-informed forward:
  R^2_log10 = 0.5792
  RMSE = 0.256752 S/m
  MAE = 0.093643 S/m

- Random Forest benchmark:
  R^2_log10 = 0.5169
  RMSE = 0.292066 S/m
  MAE = 0.099637 S/m

Important interpretation:
- In this forward-model framing, the physics-informed model currently
  outperforms the Random Forest benchmark on the linked stable-point dataset.

Moisture handling:
- moisture is now treated as an expected placeholder state variable
- the code runs with or without moisture
- current summary explicitly reports when moisture is missing

8. Main Conceptual Conclusions Reached
===============================================================================

1. A forward EC model is useful and scientifically interpretable.

2. The inverse problem is harder than the forward problem:
   soil properties -> EC does not imply EC -> soil properties is equally well posed.

3. The best project framing is:
   - forward model for mechanism
   - inverse model for application
   - optional plant-specific health score on top

4. Clay should stay in the model:
   - as a context variable, not necessarily as a health target

5. Missing ion chemistry is still likely one of the main reasons why high-EC
   behavior is hard to model well.

6. The current data support proceeding with:
   - forward modeling now
   - inverse modeling now
   - and later incorporating moisture or fuller chemistry if it becomes available
